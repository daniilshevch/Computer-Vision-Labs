# Лабораторна робота №4

## Тема

Розробка та навчання моделі детекції об'єктів на основі SSD300 для датасету Pascal VOC: генерація anchor boxes, обчислення локалізації та класифікації, а також оцінка якості детекції на реальних зображеннях.

## Мета роботи

- ознайомитися з концепцією one-stage object detection;
- реалізувати SSD-пайплайн для роботи з зображеннями 300x300;
- побудувати feature maps на різних рівнях репрезентації;
- навчитись генерувати Default Boxes / prior boxes і декодувати локалізації;
- оцінити якість детекції за допомогою IoU, NMS та порогів впевненості;
- перевірити роботу моделі на прикладах з Pascal VOC.

## Структура папки `Lab4`

- `CV_Lab4.ipynb` — основний ноутбук з реалізацією SSD300, даних, навчанням і візуалізацією результатів;
- `Images/` — в цій лабораторній основні входи беруться з датасету Pascal VOC, тому окремої папки з зображеннями в репозиторії немає;
- `weights/` — папка для чекпоінтів і ваг моделі (може створюватися під час виконання ноутбука).

## Що реалізовано в ноутбуці

### 1) Архітектура SSD300

У ноутбуці реалізована модель `SSD300`, яка є класичною одностадійною моделлю детекції:

- backbone на основі VGG-like архітектури;
- додаткові convolutional layers для 6 карт ознак різних розмірів;
- генерація default boxes для кожної feature map;
- голови для:
  - локалізації (`loc`): предикція 4 параметрів для кожного default box;
  - класифікації (`conf`): предикція ймовірностей класів для кожного box.

Основні карти ознак мають різні розміри, наприклад:

- 38x38
- 19x19
- 10x10
- 5x5
- 3x3
- 1x1

Це дозволяє детектувати об'єкти різного масштабу на одному зображенні.

### 2) Default Boxes / Prior Boxes

Для кожної feature map створюються prior boxes з різними:

- масштабами;
- співвідношеннями сторін;
- офсетами по координатах.

Це є ключовою частиною SSD, оскільки модель прогнозує не конкретні координати бокса, а зміщення від anchor box.

### 3) Обчислення IoU

У роботі реалізовано оцінку перетину між прогнозованими боксами та ground-truth боксами за схемою VOC:

- обчислення intersection over union;
- фільтрація дублюючих прогнозів;
- розмежування позитивних і негативних прикладів.

### 4) Data pipeline для Pascal VOC

Модель працює з датасетом Pascal VOC:

- `VOCDetection` з `torchvision`;
- розбір XML-анотацій;
- нормалізація зображень та перетворення bbox; 
- аугментація для training: random crop, jitter, resizing, flips;
- фільтрація складних об'єктів (`difficult`), що відрізняється в залежності від режиму тренування.

### 5) Підготовка навчального датасету

Реалізовано:

- `PascalVOCDataset`;
- кастомний `collate` для batch-пакетів;
- роботу з 2007 і 2012 серіями VOC;
- об'єднання датасетів у training pipeline;
- підтримку завантаження та локального зберігання даних.

### 6) Функція втрат

Використовується SSD loss, який складається з двох частин:

- `Localization loss` для bbox regression;
- `Confidence loss` для класифікації об'єктів / фону;
- сумарний `multi-task loss` для навчання моделі.

### 7) Безперервне навчання та чекпоінти

У ноутбуці є логіка:

- тренування на GPU / CPU;
- mixed precision (`AMP`) для прискорення навчання;
- збереження ваг після кожної епохи;
- resume training з чекпоінтами;
- робота з локальними каталогами `weights/` або Google Drive.

### 8) Детекція та постпроцесинг

Після навчання виконуються:

- предикція боксів на одному зображенні;
- застосування `confidence threshold`;
- non-maximum suppression (NMS);
- відображення боксу з класом та confidence score;
- візуалізація результатів на input- i ground-truth зображеннях.

### 9) Візуальний аналіз результатів

У ноутбуці є додаткові візуалізації:

- приклади аугментованих зображень;
- графіки навчання (`loss`, `mAP`/похідні метрики у проєкті);
- вивід default boxes;
- порівняння різних threshold значень;
- демонстрація детекції на реальних тестових картинках.

## Основні функції й блоки коду

У ноутбуці є ключові компоненти:

- `SSD300` — модель детекції;
- `L2Norm` — нормалізація карт ознак;
- `generate_prior_boxes()` — створення anchor/default boxes;
- `decode()` — декодування координат боксів;
- `predict()` — детекція на одному зображенні;
- `PascalVOCDataset` — інтерфейс до датасету;
- `train_ssd()` — навчальний цикл;
- `detect_and_draw()` — візуалізація результатів;
- `show_default_boxes()` — демонстрація prior boxes;
- `compare_thresholds()` — порівняння різних порогів впевненості.

## Основні висновки

1. SSD є класичною одностадійною моделлю детекції об'єктів, яка поєднує локалізацію та класифікацію в одному проході.
2. Default boxes важливі для роботи з об'єктами різного розміру та пропорцій.
3. Наявність feature maps різних розмірів дозволяє детектувати маленькі та великі об'єкти одночасно.
4. IoU, confidence threshold і NMS є критичними для підвищення якості предиктів.
5. Обробка VOC-датасету дає повний цикл навчання від анотацій до візуальної оцінки.
6. Практична реалізація SSD дає базове розуміння pipeline сучасного object detection, що є важливим фундаментом для подальших досліджень у комп'ютерному зорі.
